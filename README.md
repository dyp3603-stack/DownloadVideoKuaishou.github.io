# Kuaishou Downloader — GitHub Pages

1. Upload `index.html`, `style.css`, and `script.js` to a GitHub repository.
2. Enable **Settings → Pages → Deploy from branch**.
3. In `script.js`, replace `API_BASE` with your HTTPS backend URL.

GitHub Pages hosts the frontend only. The backend must run on a server supporting PHP or another server-side runtime.

Do not use this project to bypass DRM, VIP restrictions, authentication, or download content you do not have permission to use.
